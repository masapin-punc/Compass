# アプリケーション機能

このフォルダは Compass の業務機能を実装する場所です。現在は責務の整理段階で、機能ごとの Django アプリ・モデル・画面はまだ作成していません。実装する単位から Django アプリを追加し、`compass/settings.py` の `INSTALLED_APPS` に登録します。

| 実装候補 | 責務 |
|---|---|
| `projects` | プロジェクト、参加メンバー、権限、横断する監査記録 |
| `library` | 図書館、原資料、整理済み知識、方針、意思決定、出典、文書の版 |
| `budgets` | 月次予算・実績、施策への配賦、差額 |
| `initiatives` | 施策の目的・仮説・指標・振り返り |
| `tasks` | 依頼、担当、期限、結果提出、確認・差戻し、期限一覧 |
| `collaboration` | コメント、通知、メンバー間の情報共有 |
| `ai` | 権限内の検索と出典付き回答、変更候補の提案 |

上記は実装候補です。要件と依存関係を確認して境界を確定します。スケジュール表示はタスクの期限等から生成し、同じ日付の二重管理を避けます。

## 実装時の約束

- 最初に参加メンバー・権限を設計し、検索・添付資料・AI参照にも同じ制約を適用します。
- 共有情報の現在値は中央のデータベースを基準とします。Markdown は版付き出力と差分取込の対象です。
- AI が推定した担当・期限・方針は候補として保持し、採用操作を経て確定します。
- 原資料の本文と整理済み知識を区別し、出典と変更履歴を追跡します。
- 事業資料・アップロード・実データをこのコードフォルダに保存しません。

全体の設計は [ドキュメント入口](../docs/index.md) を参照してください。
