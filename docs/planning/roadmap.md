## 最初の実装候補

1. 社員・プロジェクト・文書IDと権限判定の設計。
2. 未分類メモと原資料アップロード、原本版の保持。
3. 原資料1件・大容量MD1件・予算1件を使う取込試行。
4. プロジェクト参加と文書だけの共有を区別した画面・API。
5. 2人での依頼・結果提出・確認。

既存ロジックやテストの再利用を先に評価し、機能を丸ごと無条件に書き直しません。
本番の事業資料を取込む前に、合成データ・コピーで動作を確認します。
