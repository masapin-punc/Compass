# 意思決定記録のテンプレート

docs/decisions/に `NNNN-short-title.md` として作成し、mkdocs.ymlへ登録します。
このページは雛形で、意思決定そのものではありません。

```markdown
# ADR-NNNN: 判断の名称

- 状態: 提案 / 採用済み / 廃止 / 後継あり
- 日付: YYYY-MM-DD
- 決定者・確認方法:
- 関連要件・受入条件:

## 背景
何を解決するための判断か。

## 判断内容
採用した内容と適用範囲。

## 理由・比較案
比較した案、選択理由、代償。

## 検証・反映先
確認方法、実装・文書・運用への影響。

## 変更関係
旧記録、後継記録、変更理由。
```
