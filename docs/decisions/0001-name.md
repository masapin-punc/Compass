# ADR-0001: 正式名称をCompassとする

- 状態: 採用済み
- 決定日: 2026-09-29
- 決定者: 本人
- 根拠: 「Compass いいね!」「Compassを作成し、プロジェクトにアタッチしました」という依頼

## 決定

製品・プロジェクトの表示名をCompassとします。
開発ルートは既存のD:/projects/Compass、Pythonプロジェクト名と設定パッケージはcompassです。
「図書館」は知識・資料の機能名として残します。

## 理由

知識と判断根拠をもとに、方向を決め、プロジェクトを進める構想を表すためです。

## 影響

- これからの要件・設計・運用文書はCompass/docsへ集約する。
- 旧library/P002は初期提案と経緯として保持する。
- 旧案のproject-compassという開発フォルダ名は採用せず、本人が作成したCompassを使う。
- 「羅針盤」は意味を説明する際の表現。表示名に自動的に付け足さない。

技術構成の詳細、事業データの正本切替、共有AIの利用条件を、この命名決定だけで確定しません。
