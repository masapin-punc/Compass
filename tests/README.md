# 検証

現在は Django の開発基盤と設計文書の整備段階です。業務機能の自動テストはまだありません。

## 現時点で実行する確認

PyCharm に設定された Compass の Python 環境を使用し、プロジェクトルートで実行します。

```powershell
.\.venv\Scripts\python.exe manage.py check
```

この確認で検証できるのは Django の設定整合性です。予算管理・権限・AI補助などの業務要件が満たされることを意味しません。

## 業務機能を追加した際の重点確認

- 閲覧許可のないデータが画面・検索・添付・AI回答から漏れないこと。未参加でも明示的に共有された文書だけは参照できること。
- 担当者の結果提出、確認者の受領・差戻しで正しい状態へ遷移すること。
- 予算・実績・配賦で金額の精度を保ち、重複計上しないこと。
- 原資料の本文・出典を維持し、文書の版競合を検出できること。
- AI の候補が利用者の採用前に現在の方針・担当・期限を上書きしないこと。
- 必要な操作履歴が残り、バックアップから資料とデータの対応を復元できること。

単体テストは各アプリ、複数アプリにまたがる確認はこのフォルダに配置します。テストに本物の個人情報や秘密値を含めません。
